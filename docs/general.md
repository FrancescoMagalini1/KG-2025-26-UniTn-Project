# Project N.6 Territory and Education Facilities

## Purpose:

The purpose of this project is to engineer a Knowledge Graph which models various geographical
features and different education-related facilities within a territory (e.g., Trentino) based on a precise
set of user queries and requirements, namely, Competency Questions (CQs), which the Knowledge
Graph can answer, eg -

- Which types of educational institutions are available in a specific municipality (e.g., Trento or
  Rovereto)?
- What educational facilities are located near major towns or natural landmarks (like lakes or
  mountains)?
- Which areas in Trentino have the highest or lowest number of schools?
- Are there any municipalities without access to higher education institutions?
