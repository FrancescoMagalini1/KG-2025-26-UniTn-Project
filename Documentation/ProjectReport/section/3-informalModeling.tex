\section{Informal Modeling}

\subsection{Data Alignment}
Data requires a final cleaning iteration in order to align the scraped content to the ER model presented above.
For instance while parsing schools and municipalities both the italian and german name were presented as one, or apostrophes and accents were often mixed.
Using polars and pithon this errors where fixed and all the nomenclature was unified.
