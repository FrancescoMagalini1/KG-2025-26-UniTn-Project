## Datasets overview

### Municipalities of Trentino from Wikipedia

This resource contains a list of all the municipalities ("Comuni" in italian) for the region Trentino - Alto Adige, contained from the Wikipedia website. The municipalities have been filtered to only include those belonging to the province of Trento. The information contained in this dataset includes identifiers like name, postal code and istat code, statistics like surface, population and density and geographical information like latitude, longitude, altitude and bordering municipalities (only those belonging to the Trento province have been selected)

### Vivoscuola

Vivoscuola is the main school portal for the province of Trento. It contains data regarding education institutions both public and private from the whole province of Trento.
