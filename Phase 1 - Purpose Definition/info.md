This directory contains all the material for the purpose definition phase.
That includes raw data, web scraping and api scraping scripts and data cleaning pipelines.

The _data_ folder contains the data gathered during this phase.
The _staging_ subfolder contains the raw unrpocessed data.
The _school types_ subfolder contains raw data concerning school types.
The _final_ subfolder contains the final data after the cleaning process.

The _python files_ are scripts which contains web scraping tasks and data cleaning tasks.
